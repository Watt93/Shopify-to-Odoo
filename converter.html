What was read

Odoo downloads every photo from Shopify while the file is being imported: one request per row, made by the server, before the record is written. It is by far the heaviest part of the import: on a large catalogue it turns a few seconds into several minutes, and it is the first thing to time out. Untick the box and the Image column is left out of the products file; the import then runs on text alone, and the photos can still be fetched here and added to Odoo afterwards.

Use this tab if the shop keeps its domain: every old Shopify address has to be sent to the page that replaces it in Odoo. You can use SEOWL to extract the Shopify store sitemap.

  1. Read the addresses from a sitemap — the XML of sitemap.xml, or a plain list with one address per line.
  2. Keep the path only: the domain, the query string and the anchor are dropped, because Odoo matches a redirect on the path.
  3. Leave out what has no counterpart in Odoo: the home page, the cart, the customer account, the checkout, and files such as sitemap.xml or agents.md.
  4. Drop the addresses listed twice — two rules on the same address would fight over the same request.
  5. Sort by kind, then by address: products together, then collections, pages and the blog.
  6. Write each rule as a 301, the permanent redirect, which also hands the old page’s search ranking to the new one.
  7. Give each rule a fixed id from its Shopify path, so a second import updates instead of duplicating.
  8. Leave url_to empty: an Odoo address ends with the record’s own id, so it can only be copied from the shop once the import is done. That column is yours to fill.

File to import in Odoo

  1. Import the other tabs’ files first, and build the pages of the site. A redirect is written by hand towards a page that exists — there is nothing to point at before that.
  2. Fill the url_to column, one row per line. In Odoo: a product is /shop/<product>-<id>, a category /shop/category/<category>-<id>, a blog post /blog/<blog>-<id>/<post>-<id>, and a page simply /<page>. Open the page in Odoo and copy the address from the browser rather than guessing the number.
  3. A row whose url_to is still empty is refused by Odoo: delete it, or set its redirect_type to 404 to retire that address for good.
  4. Turn on the developer mode, then import from Website → Configuration → Redirects → ⚙ → Import records.
  5. Click Test first, then import. Never tick I want to update data — the id column already makes a second import update the same rules.
  6. The rules only answer once the domain points at Odoo: while the shop is still served by Shopify, the old addresses never reach Odoo at all.
